客户端可以通过SCAN特性负载均衡地连接到RAC数据库
show parameter listener         查看服务端的local_listener和remote_listener参数

[grid@pos2 ~]$ lsnrctl status listener          本地监听查看 
[grid@pos2 ~]$ lsnrctl status listener_scan1     scan监听查看

   SCAN监听器的注册是由REMOTE_LISTENER参数控制的，任何实例都会向所有的SCAN监听器注册：
show parameter remote_listener    remote_listener指向的是scan监听名
srvctl start listener   -n node1         rac中，grid用户下启动节点1的监听
srvctl status listener         本地监听状态查看    
srvctl start listener          启动所有监听
srvctl status scan_listener    查看scan listener的运行节点

srvctl config scan             查看 SCAN 的配置信息  scan ip 状态
srvctl config scan_listener    查看SCAN监听器配置信息
srvctl status scan             查看 SCAN VIP 节点分配状态   
srvctl status scan_listener     查看SCAN Listener的运行节点                                               
srvctl stop scan_listener      停止scan监听
srvctl stop listener -n node1  停止节点1的监听

srvctl config nodeapps -a      查看rac中vip的名字,ip,网卡信息
srvctl config vip -n rac1      查看指定节点的vip配置信息

srvctl config database         查看集群中的数据库信息
