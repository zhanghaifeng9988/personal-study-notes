问题3：如何对pdb$seed做状态更改，默认状态是read only
SYS@ prod1>alter session set container=pdb$seed;

会话已更改。

SYS@ prod1>select TABLESPACE_NAME,STATUS,BIGFILE,SHARED,CON_ID from cdb_tablespaces;

+DATA/PROD/E8273994F38C6F18E0535803A8C095BE/TEMPFILE/temp.268.1114878591
TEMP                           SHARED                            2

需要更改pdb$seed状态，
SQL> alter session set "_oracle_script"=true;

Session altered.

SQL> alter pluggable database pdb$seed close immediate;

Pluggable database altered.

SQL> alter pluggable database pdb$seed open;

Pluggable database altered.

SQL> show pdbs

    CON_ID CON_NAME             OPEN MODE RESTRICTED
---------- ------------------------------ ---------- ----------
     2 PDB$SEED             READ WRITE NO
	 
特别注意：如果环境是rac的话，上述步骤第一步和第二部，需要在每个节点上单独执行，
完成后，在每个节点执行第三步。

SQL> alter pluggable database pdb$seed close immediate;

Pluggable database altered.

SQL> alter pluggable database pdb$seed open read only;

Pluggable database altered.

特别注意：如果环境是rac的话，上述步骤第一步需要在每个节点上单独执行，
完成后，在每个节点执行第二步。
