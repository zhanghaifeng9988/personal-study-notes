

# 标题
使用 # 号来创建标题，# 的数量表示标题的级别。
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题


# 强调
使用星号（*）或下划线（_）来表示斜体或粗体。

*斜体文本* 或 _斜体文本_
**粗体文本** 或 __粗体文本__

***粗斜体文本*** 或 ___粗斜体文本___

任务列表通常用于GitHub的Markdown中，使用方括号和空格来表示未完成的任务，使用方括号和x来表示已完成的任务。
- [ ] 任务一
- [x] 任务二
- [ ] 任务三

# 行首字符前面空4个空格，会以独立的显示区域进行显示
    首字母前面空4个空格，转换html后，会让本行的内容再页面中成为一个可以横向拖动的显示内容框部分，只要没有换行，内容一直再这个区域内显示，且是单行显示所有内容。如果要换行，那就敲回车后，按退格键，行首不再是4个空格，如下所示，就换行了，如果不按退格键把前面个的4个空格删掉，只按回车键，那接下来的内容还是在这个区域中以单行方式显示所有内容
  注意：**这是换行的示例**：如果换行了，行首不是空4个空格，就不在上面那样的区域显示内容了。

# 文档内容换行的一些**用法**
## 默认换行方式（不用插件的情况，我现在这个插件不用这么麻烦了，回车直接换行）
如果文档内容多，默认换行，建议：**行尾**要先敲**两个空格**，然后回车换行，或者shift+回车换行。  
就是这样，需要特别注意！！不是直接敲回车换行。
## 其他情况 （不用插件的情况，我现在这个插件不用这么麻烦了，回车直接换行）
如果紧接上一行内容（没有空行），无论行首前面空几个空格，转html后，都是和上一行文档紧挨着。
    **挨着挨着挨着**  

如果和上一行中间有空行，那就自动换行了。  

## 提示：所有的**标题**，**列表**后面跟的内容，只要**回车换行，或者shift+回车换行**都会换行
上面这个就是二级标题，本行内容，就是我直接使用回车进行了换行。  
区别：标题所在行，换行后，直接就是正文内容。如果是在列表中，进行回车换行，列表格式会换行继续。  
想要换行，那就空一行，或者列表末尾敲两个空格，然后回车。
1. 列表1
2. 列表2
