mariadb更改binlog的方法，见如下链接：
https://www.cnblogs.com/chong-zuo3322/p/14551869.html
增加对mariadb的配置，开启binlog：
vim /etc/my.cnf.d/server.cnf
在[mysqld]一节中增加下列配置：
log-bin=mysql-bin
max-binlog-size=1G
expire_logs_days=180

#如果启用了这一行，则会使得binlog更大，但是最安全。

binlog_format=row

保存后，重启mariadb服务：
systemctl restart mariadb
登录mysql后执行：
SHOW VARIABLES LIKE 'log_bin';
如果提示：
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| log_bin       | ON    |
+---------------+-------+
1 row in set (0.002 sec)

则说明binlog开启成功，然后执行：
SHOW BINLOG EVENTS;
如果显示数据库操作记录，则说明binlog启用成功。
也可以进入mariadb的data——dir中查看二进制日志文件是否已经产生：
cd /home/mariadb/
ll
如果显示类似的文件，则说明binlog成功：
mysql-bin.000001
mysql-bin.index

创建用户：
create user 'tapdata'@'localhost' identified by 'password';
create user 'tapdata'@'%' identified by 'password';

给用户授权：注意如果加上@及后面的内容则是在创建用户的同时，给予用户授权
grant all privileges on *.* to tapdata2@localhost identified by 'password';
grant all privileges on *.* to tapdata2@'%' identified by 'password';
flush privileges;记得刷新一下
