# DoraFactory

## 介绍

DoraFactory是一个基于区块链的去中心化应用市场，用户可以发布应用、购买应用、交流应用信息、评价应用。DoraFactory的目标是打造一个开放、透明、可信的应用市场，让用户能够自由地发布、购买、交流、评价应用。
1. Dora Factory 的产生是由 DoraHacks 孵化的去中心化治理基础设施。
2. DoraHacks 成立于 2014 年，是全球最大最活跃、坚持时间最长的开源极客平台，也是多链 Web 3 领域最活跃的开源开发者激励平台和中文世界最具有影响力的极客和开发者社区。
3. DoraHacks 成立于 2014 年，是全球最大最活跃、坚持时间最长的开源极客平台，也是多链 Web 3 领域最活跃的开源开发者激励平台和中文世界最具有影响力的极客和开发者社区。
4. 主要的 Web3 生态和开源开发者社区，都是通过与 DoraHacks 合作来链接全球开发者和社区。


## 应用场景

- 应用发布者：发布应用，向DoraFactory平台发布应用，将应用信息上链，获得应用的独特标识，并获得应用的下载地址。
- 应用购买者：购买应用，通过DoraFactory平台购买应用，选择应用的独特标识，下载应用。
- 应用交流者：交流应用信息，通过DoraFactory平台与其他用户交流应用信息，分享自己的使用心得。
- 应用评价者：评价应用，通过DoraFactory平台对应用进行评价，分享自己的使用体验。

## 应用架构

DoraFactory的应用架构分为四层：

- 应用发布层：用户发布应用，将应用信息上链，获得应用的独特标识，并获得应用的下载地址。
- 应用购买层：用户购买应用，通过DoraFactory平台购买应用，选择应用的独特标识，下载应用。
- 应用交流层：用户交流应用信息，通过DoraFactory平台与其他用户交流应用信息，分享自己的使用心得。
- 应用评价层：用户评价应用，通过DoraFactory平台对应用进行评价，分享自己的使用体验。

## 应用流程

- 用户发布应用：用户发布应用，将应用信息上链，获得应用的独特标识，并获得应用的下载地址。
- 用户购买应用：用户通过DoraFactory平台购买应用，选择应用的独特标识，下载应用。
- 用户交流应用信息：用户通过DoraFactory平台与其他用户交流应用信息，分享自己的使用心得。
- 用户评价应用：用户通过DoraFactory平台对应用进行评价，分享自己的使用体验。

## 应用特点

- 去中心化：DoraFactory是一个去中心化的应用市场，用户可以自由地发布、购买、交流、评价应用。
- 透明度：DoraFactory平台上所有信息都是公开透明的，用户可以随时查看自己的交易记录、评价记录、下载记录。
- 安全性：DoraFactory平台采用区块链技术，用户的应用信息上链，交易记录不可篡改，确保应用的安全性。
- 免费下载：DoraFactory平台上所有应用都是免费下载的，用户可以随时下载应用。
- 免费注册：DoraFactory平台无需注册，用户可以直接登录平台购买、交流、评价应用。 

## 应用价值

- 降低应用开发门槛：DoraFactory平台上所有应用都是免费下载的，用户可以直接下载应用，无需开发者注册。
- 提升应用质量：DoraFactory平台上所有应用都是经过审核的，确保应用的质量。
- 促进应用交流：DoraFactory平台上所有应用信息都是公开透明的，用户可以随时查看自己的交易记录、评价记录、下载记录。
- 促进应用流通：DoraFactory平台上所有应用都是免费下载的，用户可以随时下载应用，促进应用流通。
