# 价格文件、商务技术文件、资格证明文件三部分组成。**每部分应当分别编制目录**
# 表格各列不得自行增减，不得调整顺序。
# 询价文件已经明确物资明细的，应当严格按照明确的物资名称填写各行内容，不得自行增减
# 报价文件的正本与副本应当分别装订成册。副本份数：2份；电子版报价文件（介质为光盘）：1份。
# 电子版报价文件为纸质价格文件、商务技术文件、资格证明文件正本的PDF格式和DOC格式文档，目录与相应内容具有链接索引功能，文件名格式：“第X包-项目名称-报价供应商名称”。
# 报价文件中“价格文件”应当与“商务技术文件”和“资格证明文件”分开单独密封包装，并在封套的封口处加盖报价供应商公章。
# **评审方法：经评审的最低价法**，是指报价文件满足询价文件资格性和符合性要求，将报价最低的报价供应商，作为预成交供应商的评审方法。
# 报价供应商制作报价文件时，应当对照《资格性审查表》《符合性审查表》提供尽可能详细的证明材料。
# 所有单价和总价按照“报价一览表”格式要求填报。报价应当包括货款、标准附件、备品备件、专用工具、包装、安装、调试、培训、保修等费用和税金。

**报价地点：**福建省厦门市集美区后溪镇坂头水库西门。
**报价方式：**由报价供应商法定代表人或授权代表现场提交报价文件，不接受邮寄等其他方式。
# 最高限价：30万元。
