                                   /etc/profile  .bash_profile  .bashrc 的讲解

/etc/profile
用于设置系统级的环境变量和启动程序，在这个文件下配置会对所有用户生效。
当用户登录(login)时，文件会被执行，并从/etc/profile.d目录的配置文件中查找shell设置。
会在用户登录(login)时生效，也可以用于设置环境变理。

~/.bash_profile
用于”登录shell”的环境加载，这个”登录shell”既可以是”交互式”的，也可以是”非交互式”的
只对单一用户有效，文件存储位于~/.bash_profile，该文件是一个用户级的设置，可以理解为某一个用户的profile目录下。

登陆过程：
1. 读取并执行/etc/profile文件；
2. 读取并执行~/.bash_profile文件；
- 若文件不存在，则读取并执行~/.bash_login文件；
- 若文件不存在，则读取并执行~/.profile文件；

~/.bashrc
用于”交互式非登录shell”的环境加载。
系统级的位于/etc/bashrc、用户级的位于~/.bashrc，两者分别会对所有用户和当前用户生效。
通常是bash shell调用另一个bash shell时读取，也就是在shell中再键入bash命令启动一个新shell时就会去读该文件。这样可有效分离登录和子shell所需的环境。

                            正则表达式的() [] {}有不同的意思。
() 是为了提取匹配的字符串。表达式中有几个()就有几个相应的匹配字符串。

(\s*)表示连续空格的字符串。

[]是定义匹配的字符范围。比如 [a-zA-Z0-9] 表示相应位置的字符要匹配英文字符和数字。[\s*]表示空格或者*号。

{}一般用来表示匹配的长度，比如 \s{3} 表示匹配三个空格，\s{1,3}表示匹配一到三个空格。

(0-9) 匹配 '0-9′ 本身。 [0-9]* 匹配数字（注意后面有 *，可以为空）[0-9]+ 匹配数字（注意后面有 +，不可以为空）{1-9} 写法错误。

[0-9]{0,9} 表示长度为 0 到 9 的数字字符串。

替换运算符：
 ${varname:-word}      存在且非null 返回varname 否则返回word
 ${varname:=word}      存在且非null 返回varname 否则赋值word
 ${varname:？message}  存在且非null 返回varname 否则打印message
 ${varname:+word}      存在且非null 返回word    否则返回null
 每个冒号都是可选的，如果省略冒号，则表示判断变量是否“存在”

模式匹配运算符：
${varname#pattern}     匹配变量取值的开头处，则删除匹配的最短部分，返回剩下部分
${varname##pattern}    匹配变量取值的开头处，则删除匹配的最长部分，返回剩下部分
${varname%pattern}     匹配变量取值的结尾处，则删除匹配的最短部分，返回剩下部分
${varname%%pattern}    匹配变量取值的结尾处，则删除匹配的最长部分，返回剩下部分
匹配模式的最长部分替换为string
${varname/pattern/string}  只匹配第一部分，被替换为string
${varname//pattern/string} 匹配所有的部分，被替换为string

												   sed  流编辑器
sed--version   查看sed的版本,这是一款流编辑器
               sed是基于行的，按顺序对每一行执行命令
			   它不修改任何输入文件
               养成使用单引号来括起sed命令的习惯，这样可以禁用shell的扩展
	工作顺序：1、从指定的输入读入一行数据存入被称为模式空间（pattern space）的临时缓冲区
              2、按照指定的sed编辑命令，处理缓冲区的内容
              3、把缓冲区的内容送到指定的输出并且将这些内容从模式空间中删除
              4、回到第一步继续下一次工作			  
			   sed -e '/^#/d' /etc/rc.local  删除（不显示）#号开头的行   
               sed -e '1,19d' passwd.bak     删除（不显示）1-19行的内容
			  sed中使用规则表达式，需要使用两个/（即/  /） 将规则括起来
                
				d 删除行命令    p 打印行命令   i 插入行命令  a  在某行某位置追加内容的命令
				
	 -n       该参数告诉sed，除非明确要求打印模式空间，否则不这样做。（即使用p打印命令的时候，如果不打印模式空间内容，需要加-n参数）
	             sed -n -e '/^#/p' /etc/rc.local
	
	 \	      反斜杠可以将元字符转换为普通字符 
	 
			  若果sed中包含多重判断，则需要[]，看如下示例，表示删除不是#开头的行
			  
			  sed -e '/^[^#]/d'  /etc/rc.local
	
	[[:sapce:]]  这是一个特殊的关键字，他告诉sed，与TAB键或者是空格键匹配 
	 
	 替换命令的格式:  
	                's/查找的内容/替换的内容/'      -该命令替换操作只能对文本中第一次出现的查找内容有效
					's/查找的内容/替换的内容/g'     -末尾的g告诉sed执行全局替换 
	
	sed试图在行中匹配规则表达式时，他要在运行中查找最长的匹配。——————这个特性非常重要
	
	sed -n -e '=;p' passwd.bak      '=;p' 表示：打印行号
	
	-e command, --expression=command    允许多台编辑。
    -h, --help                          打印帮助，并显示bug列表的地址。
    -n, --quiet, --silent               取消默认输出。

                                         进程
	进程就是运行中的程序，一个正在运行的程序，可能有多个进程。
	一个进程是一个程序的一次执行的过程，程序是静态的，他是一些保存在磁盘上的可执行的代码和数据集合，进程是一个动态的概念。
	父进程和子进程的关系是管理和被管理的关系，当父进程终止时，子进程也随之终止，但子进程终止时，父进程并不一定终止。
	在同一时间，系统里有很多进程，通过时间片的方式获得cpu资源，并一起运行。
	pstree  查看进程树
	ps aux  可以查看到进程对系统资源的占用情况
	ps -ef
	进程编号0通常被称为kernel，sched或swapper；
	进程编号1称为init，它是所有进程的父进程或祖先进程；
	在关机时，进程的退出是根据ID由大到小的顺序依次执行，直到init。当init进程结束后，系统便终止。
	top  监控着一段时间内系统的运行状态，包括负载、cpu使用状况、内存使用状态、进程状况等。
	
	
	                                shell命令的执行
	shell命令分成内置命令和外部命令
	内置命令：是shell解释程序内建的，由shell直接执行，不需要派生新的进程。
	常见的内部命令：. (点命令） bg  cd  continue echo exec exit export fg  jobs pwd read  return set shift test times trap umask unset wait等
	外部命令：shell会创建一个新的进程来执行命令。当命令的进程运行时，默认shell将等待直到该进程结束。
	外部命令两种：1、二进制代码  2、shell脚本
	常见的外部命令有：grep  more cat mkdir rmdir ls sort ftp telnet ssh ps等
	
	linux通过fork（）调用来创建一个新的进程，fork会创建原有进程的贮存的精确复制。
	调用fork的进程是父进程，而由fork创建的进程是子进程，也就是说：一个父进程通过fork创造了一个和它一模一样的子进程。
	
	linux使用exec执行二进制的外部命令；
	shell脚本的执行：shell解释程序会fork一个子shell进程，该进程会检查脚本的第一行（如！#/bin/sh），找到用来执行脚本的解释程序
	  然后装入这个解释程序，由它解释执行脚本程序
	
	手工启动进程分为两种：前台启动和后台启动
	   前台启动：是手工启动一个进程的最常用的方式
	   后台进程启动：直接在命令的末尾增加一个字符&
	 中断一个前台进程的时候，通常使用ctrl+c
	 中断一个后台进程，需要使用kill
	 前台进程和后台进程可以相互转换。ctrl+z 挂起前台进程，bg命令将前台程序转成后台运行。fg命令可以直接将后台程序转换为前台运行。
	 
	 jobs命令显示当前shell被挂起的进程和后台进程的状况。
	 
	                                                    信号

	kill -sigtstp 进程号     表示：挂起进程，和ctrl+z 组合键产生的信号是一样的。
	kill -sigint  进程号     表示：中断进程的信号，相当于按ctrl+c组合键产生的信号一样的。

	                                                     线程
	当你在一台linux pc上打开两个qq，每一个qq是一个进程，而当你在一个qq上和多人聊天时，每一个聊天窗口就是一个线程。
	
	线程和进程都是用于并行处理，但是他们的实现和应用场景不同。
	
	线程（thread）是在共享内存空间中并发的多道执行路径，他们共享一个进程的资源，如文件描述和信号处理。
	
	在串行程序基础上引入线程和进程是为了提高程序的并发度，从而提高程序运行效率和响应时间。
	pthread 是一种标准化模型，它用来把一个程序分成一组能够同时执行的任务。
	
	进程是通过系统调用fork创建的，新的进程是原来进程的子进程；
	linux中的线程也是通过fork创建的，是轻进程。

& 符号的作用
Linux 终端命令的末尾加上一个 & 符号表示将这个任务放到后台去执行，例如以下命令表示将复制任务放到后台执行：

cp -R original/dir/ backup/dir/ &
1
对于需要长时间执行的任务，&符号可以使当前终端窗口不被占用，这样就能继续在同一个终端上工作，甚至关闭终端窗口也不会影响任务的正常执行。不过需要注意的是，如果要求这个任务输出内容到标准输出中（例如 echo 或 ls），即便使用了 &，也会等待这些输出任务在前台运行完毕

当使用 &将一个进程放置到后台运行的时候，Bash 会提示这个进程的进程 ID。在 Linux 系统中运行的每一个进程都有一个唯一的进程 ID，我们可以使用进程 ID 来暂停、恢复或者终止对应的进程，因此进程 ID 是非常重要的
