



空间计算时代：
    空间计算平台：将全面颠覆平面计算的范畴，帮助人实现虚拟与现实之间的连通与融合的计算过程。
	空间计算的定义:在三维的基础之上，以人为本，连通及融合虚拟世界与现实世界的一个 全新的计算范式。

“在三维的基础之上”，是指空间计算的客体对象如果本身是三维的，
不再需要从三维降维至二维的平面以方便计算和跟用户的交互，而是可以保持为立体的三维的， 
这是空间计算的基础。	

“以人为本”，是指空间计算的主体仍然是人，空间计算的目的是服务人与虚拟世界的交互。

“连通与融合虚拟世界与现实世界”则描述了空间计算的过程与适用范畴。

MR 眼镜这一空间计算设备所开启的空间计算平台

第一大场景：虚拟现实 + to C → 顺人性：各类娱乐类、社交类应用、内容、产品等；

第二大场景：虚拟现实 + to B/G → 顺人性：各类办公类、业务类应用、产品、服务等；

第三大场景：人机共生/协同 + to C → 顺人性：如家庭端的服务型机器人；

第四大场景：人机共生/协同 + to B/G →顺人性：如应用于医疗领域的脑机接口；

第五大场景：虚拟现实 + to C → 逆人性：如学生的网课、健身应用等；

第六大场景：虚拟现实 + to B/G → 逆人性：如考勤/规范类的应用、产品、服务；

第七大场景：人机共生/协同 + to C → 逆人性：如机器人管理员类的应用、产品；

第八大场景：人机共生/协同 + to B/G → 逆人性：如管理类的应用、产品、服务。

苹果CEO库克表示，“如同Mac将我们带入个人计算时代，iPhone将我们带入移动计算时代，
Apple Vision Pro将带我们进入空间计算时代”。

随着MR设备的应用扩展，也将为软件开发和内容制作公司带来商机。

MR（Mix Reality，混合现实）将 AR （Augmented Reality，增强现实）
和 VR（Virtual Reality，虚拟现实）的优点结合在一起，通过一系列的摄像头和传感器捕捉现实世界，
然后将其投射在用户眼前的显示器上。
