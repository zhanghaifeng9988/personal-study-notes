

                --.NET MAUI--

  .NET 多平台应用 UI (.NET MAUI) 是一个跨平台框架，
用于使用 C# 和 XAML 创建本机移动和桌面应用。使用 .NET MAUI，
可从单个共享代码库开发可在 Android、iOS、macOS 和 Windows 上运行的应用。

  .NET MAUI 提供了用于为移动和桌面应用生成 UI 的单一框架。
  
  
             --Avalonia--
  Avalonia 是一个开源的、跨平台的 UI 框架，旨在为 C# 开发人员提供一种简单且强大的方式来构建桌面应用程序。

借助 Avalonia，开发人员可以使用 XAML 和 C# 来创建应用程序，
而这些应用程序可以在 Windows、Linux 和 macOS 等多个操作系统上无缝运行。

Avalonia 提供了高性能、灵活性和易用性，使得开发跨平台应用程序变得更加轻松。


            --WPF--
  WPF（Windows Presentation Foundation）
WPF 是一个用于构建Windows桌面应用程序的UI框架。
它提供了丰富的数据绑定、样式、动画和图形功能，允许开发者创建复杂的用户界面。
WPF 使用XAML作为其界面描述语言，并支持MVVM（Model-View-ViewModel）模式。  



              --ASP.NET--  （后端技术）
	ASP.NET（Active Server Pages .NET）是一个用于构建Web应用程序的服务器端框架，它是.NET平台的一部分。
ASP.NET提供了一套丰富的工具和功能，使得开发者能够创建动态、交互式的Web界面。


  
               --Blazor--  （前端技术）
			   
  Blazor 是一个开放源代码和跨平台的Web UI框架，
使用 C#代替 JavaScript 来创建丰富的交互式 UI。
Blazor支持2种运行模式：
  Blazor Server模式：应用在ASP.NET Core应用服务器上运行，
并且通过SignalR（双向通讯）进行用户交互处理；
  Blazor WebAssembly 模式：Razor和HTML最终会编译成WebAssembly 运行在支WebAssembly 的浏览器上。


  
			   --Razor--  （前端技术）
  Razor 是一种用于.NET的服务器端模板引擎，它允许开发者使用HTML标记和C#代码混合编写的方式来创建Web页面。
Razor的主要目标是简化Web开发，使得编写和维护Web应用程序的用户界面变得更加容易和高效。
