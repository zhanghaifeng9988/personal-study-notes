
#TypeError: __str__ returned non-string (type set)

解释：__str__方法只能返回字符串类型的数据，不能返回dict和set类型

举例：
 #错误的写法：
  def __str__(self):
        return {
            'Student object (name:%s)' % str(self.__name),
            'Student object (age:%s)' % str(self.__age),
            'Student object (score:%s)' % str(self.__score)
            }

 #正确的写法：
def __str__(self):
        return 'Student object (name:%s, age:%s, score:%s)' % (str(self.__name), str(self.__age), str(self.__score)) 
 
 #以下为，采用正确的写法，Student类初始化数据值后的显示

Student object (name:Bart Simpson, age:19, score:88)

Student object (name:Bart Simpson, age:19, score:88)

 #查看实例对象的字典属性
>>> print(bart.__dict__)
