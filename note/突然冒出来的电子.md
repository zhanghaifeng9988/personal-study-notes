# 教育培训
如果我来办培训机构，那我采取的费用策略是：
1. 学院只需要缴纳学习保证金，如果不能保证正常和约定的学习内容，保证金不予退还；
保证金为学费的10%；
2. 学生每个阶段的学习内容，经考核合格后，给与阶段认证和奖励，如果当前阶段没有通过
学生还有一次学习机会，如果不能通过，则必须退出学习，且扣除保证金的20%；扣除比例是按照学习阶段数量来对应计算的百分比，5个学习阶段的话，重新学习一次任意阶段，扣除保证金的20%，如果发生保证金扣除完毕的情况，需要学员继续缴纳保证金才能继续学习。
3. 只有全部完成所有阶段学习和考核任务的学员，才能拿到最终认证；
4. 获得最终认证的学员，在拿到认证前，需要缴纳学习费用和认证费用；

## 其他途径学习的东西
### 接手1个团队，如何成为团队的领袖
1.团队见面，核心人员1V1面谈，让每个人写下个人发展计划，做第一轮人员考察;
2.建立会议机制，周会、月会、项目会议，解业务、发现团队薄弱点、继续观察人员、管理进度;
3.在摸清团队能力下，进行人才梯队补强，外聘强将带兵;
4.推行项目管理+数据分析的工作方式，教大家做事和表达的逻辑思维，让大家拥有统一的工作思路;
5.不看出身，只看能力，把自己看重的人给到更大的曝光，找到时机进行提拔，树榜样，做激励;
6.该为下属争取的激励一定争取，该挡的刀他站出来挡，随时做好为下属兜底的准备;
7.向不同的下属请教技术问题，自学技术，减少与团队的沟通障碍

# 创业理念
团队没有独裁者，也不褒奖孤勇者。方向由领导者守护，目标由实践者兑现，协作由合作者连接。每个人先做自己的管理者——自由意味着自我负责，爱意味着坦诚相待。个人成为更好的自己，团队自然成为更好的团队                                                                                                                                            自由 → 但信息必须透明，决策必须留痕；

爱 → 但可以激烈争论，不许背后议论；

反独裁 → 但允许"临时指挥官"在明确时限内拍板；

反孤勇 → 但救火之后必须复盘，把英雄行为变成流程。
