# 一、什么是异步操作？
在 JavaScript 中，许多操作是异步的，意味着它们不会立即完成。例如：
1. 网络请求（例如从服务器获取数据）
2. 读取文件
3. 定时器（setTimeout）
因为这些操作需要一些时间来完成，JavaScript 不会在这些操作未完成时停止执行后面的代码。相反，它会在**等待操作完成的时候继续执行其他代码**，这就是异步操作的基本概念。

# 二、什么是 Promise？
Promise 是一个用于表示异步操作最终完成情况（或失败）及其结果值的类。

Promise 通过它的构造函数生成对象，构造函数的参数是个回调函数，该回调函数接收两个参数：
1. resolve：用于将 Promise对象的状态从 "pending" 改为 "fulfilled"，并返回一个结果值。
2. reject：用于将 Promise对象的状态从 "pending" 改为 "rejected"，并返回一个错误原因。

Promise的对象，可以是下面三种状态之一：
1. pending（进行中）: 初始状态，表示操作尚未完成。
2. fulfilled（已完成）: 表示操作成功完成，并提供了结果值。
3. rejected（已失败）: 表示操作失败，并提供了错误原因。

**promise的构造函数中，包含了异步程序的代码。**

# 三、Promise 的基本用法
Promise 的创建通常通过构造函数来实现：

const myPromise = new Promise((resolve, reject) => {
   setTimeout(() => {// 模拟异步操作
        const success = true; // 模拟操作成功
        if (success) {
            resolve("操作成功！");
        } else {
            reject("操作失败！");
        }
    }, 1000);
});

const myPromise = new Promise((resolve, reject) => {
    // 异步操作
    const success = true; // 模拟操作成功

    if (success) {
        resolve("操作成功！"); // 操作完成，调用 resolve
    } else {
        reject("操作失败！"); // 操作失败，调用 reject
    }
});


resolve(value)：将 Promise 状态从 "Pending" 改为 "Fulfilled"，并返回 value。
reject(error)：将 Promise 状态从 "Pending" 改为 "Rejected"，并返回 error。
你可以使用 .then() 和 .catch() 方法来处理完成或失败的结果：

myPromise.then(result => {
    console.log(result); // 输出 "操作成功！"
}).catch(error => {
    console.error(error); // 输出 "操作失败！"
});


# 四、什么是异步函数（async 函数）？
async 函数是使用 async 关键字定义的函数，具有以下特点：

1. 总是返回一个 Promise对象。
2. 可以使用 await 关键字等待其他 Promise。
**定义异步函数的示例：**
const fetchData1=async function fetchData() {
    return "数据获取成功！"; // 这里的返回值会被包装成一个 Promise
}

这里虽然直接返回了一个字符串，但 fetchData() 实际上会返回一个 Promise：

fetchData1().then(result => console.log(result)); // 输出 "数据获取成功！"

# 五、await 的使用
await 关键字只能在 async 函数中使用。它的作用是：
暂停异步函数的执行，直到等待的 Promise 完成。
如果 Promise 成功完成，await 将返回 Promise 的结果值。
如果 Promise 被拒绝，await 将抛出异常，可以通过 try...catch 捕获。

## 使用 await 的示例：
async function fetchData() {
    const response = await new Promise((resolve) => {
        setTimeout(() => {
            resolve("数据获取成功!");
        }, 2000); // 模拟一个耗时的操作
    });
    return response;
}

async function main() {
    const result = await fetchData(); // 等待 fetchData() 完成
    console.log(result); // 输出 "数据获取成功!"
}

main(); //输出 "数据获取成功!"
fetchData().then(result => console.log(result)); // 输出 "数据获取成功!"

## 注意事项
如果没有第一个 await，fetchData 会立即返回一个**未完成的 Promise**，response 会是一个 Promise 对象，而不是 "数据获取成功!"。
如果没有第二个 await，main 函数会立即执行 console.log(result)，而 result 会是一个**未完成的 Promise 对象**。


# 总结
实现异步函数：只需要用 async 定义函数即可。
等待异步操作的结果：必须在调用异步函数时加 await。
不等待结果：可以不加 await，但此时你只能得到一个 Promise 对象。

# NestJS 中的依赖注入
## 什么是依赖注入？
依赖注入（Dependency Injection，DI）是一种设计模式，它用于解耦对象之间的依赖关系。

依赖注入的基本思想是：**一个对象不应该创建它所依赖的对象，而是应该通过参数（或其他方式）来接收依赖对象。**

## ts的依赖注入举例
### 一个类，依赖于另一个类的数据，**传统的做法如下**：
class UserRepository {
    findUserById(id: number): string {
        // 模拟从数据库获取用户
        return `User ${id}`;
    }
}

class UserService {
    private userRepository: UserRepository = new UserRepository();
    getUser(id: number): string {
        return this.userRepository.findUserById(id);
    }
}


const userService = new UserService();
console.log(userService.getUser(1)); // 输出: User 1

**特点：** UserService 直接依赖于 UserRepository 的具体实现，导致代码耦合度高，难以测试和维护。
**个人理解的直接依赖**：被依赖的类，需要在依赖他的类中进行实例化，这样的话
1. 被依赖的类必须在实例化的时候就存在，否则会报错。
2. 被依赖的类的实例化的参数是写死的，无法灵活调整。


### 使用依赖注入的做法，**构造函数实现依赖注入**：
class UserRepository {
    findUserById(id: number): string {
        // 模拟从数据库获取用户
        return `User ${id}`;
    }
}

class UserService {
    private userRepository: UserRepository;

    // 构造函数注入,通过构造函数接收一个 UserRepository 实例。
    constructor(userRepository: UserRepository) {
        this.userRepository = userRepository;
    }

    getUser(id: number): string {
        return this.userRepository.findUserById(id);
    }
}

**另一种写法**
class UserService {
    // 构造函数注入,通过构造函数接收一个 UserRepository 实例。
    constructor(private readonly userRepository: UserRepository) {
        
    }

    getUser(id: number): string {
        return this.userRepository.findUserById(id);
    }
}


// 使用
const userRepository = new UserRepository();// 实例化被依赖的类
const userService = new UserService(userRepository); // **依赖注入**
console.log(userService.getUser(1)); // 输出: User 1

**依赖关系由外部代码（调用者）管理，实现了控制反转。**


## NestJS 中的依赖注入
## 依赖注入的流程
1. 声明依赖：在类的构造函数中声明需要的依赖。
2. 注册依赖：在模块的 providers 中注册依赖。
3. 注入依赖：NestJS 的依赖注入容器会自动创建依赖实例，并将其注入到需要它的类中。

NestJS 内置了强大的依赖注入机制，通过 @Injectable() 装饰器和 @Module() 装饰器来实现。

步骤 1：在service.ts 中，定义可注入的服务 
使用 @Injectable() 装饰器标记一个类为可注入的服务。
@Injectable()
export class UserService {
  getHello() {
    return 'Hello World!';
  }
}

步骤 2：在module.ts 模块中，注册服务
在模块的 providers 数组中注册服务。
@Module({
  providers: [UserService],
})
export class UserModule {}


步骤 3：在控制器或其他服务中注入
通过构造函数注入服务。
@Controller('users')
export class UserController {
  constructor(private readonly userService: UserService) {}

  @Get()
  getHello() {
    return this.userService.getHello();
  }
}
