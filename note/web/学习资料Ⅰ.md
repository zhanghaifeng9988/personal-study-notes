# nodejs安装
[https://blog.csdn.net/Javachichi/article/details/132868889]
# 常用命令
- node -v
- npm -v
- npm config set prefix  "D:\Program Files\nodejs\node_global"
- npm config set cache  "D:\Program Files\nodejs\node_cache"
# 配置过程
## 1.查看初始npm源
- npm config get registry
## 2.更换npm源
- **这个淘宝的不用了** npm config set registry https://registry.npm.taobao.org/  
- **用这个** npm config set registry http://registry.npmmirror.com/
## 3.查看npm配置修改是否成功
npm config list

## 4.环境变量的修改
- 删除掉的环境变量值：在我的电脑中，此处做个备份
 C:\Users\Administrator\AppData\Roaming\npm
- 用户变量path中，添加两个变量值：
D:\Program Files\nodejs\node_global
D:\Program Files\nodejs
- 用户变量新建一个：NODE_PATH，值为：
D:\Program Files\nodejs\node_global\node_modules
- 系统变量，Path添加上   %NODE_PATH%
  
## 5.vue安装
-  npm install vue -g
## 6.安装webpack模板
- npm install webpack -g
- 此外，在webpack 4x以上，webpack将命令相关的内容都放到了webpack-cli，所以还需要安装webpack-cli
- npm install webpack-cli -g
- 输入 webpack -v，能输出版本号就说明都安装好了。

## 7.安装脚手架vue-cli
- npm install vue-cli -g
- 输入vue --version，能输出版本号就说明安装好了。
  
## 8.安装vue-router
- npm install vue-router -g

## 9.都弄好了我们打开我们自定义的全局模块目录下的node_modules文件夹，会发现安装的模块都统一在这里。
