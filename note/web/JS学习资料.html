JavaScript 语法

JavaScript 是一个脚本语言。 它是一个轻量级，但功能强大的编程语言。

JavaScript 字面量

一般固定值称为字面量 JavaScript 字面量是指直接表示值的表达式。 JavaScript 有以下几种字面量：

  • 字符串字面量 "John Doe" 'John Doe'
  • 数字字面量 3.14 1001 123e5
  • 布尔字面量 true false
  • 数组字面量 [1, 2, 3, 4, 5]
  • null 字面量 null
  • undefined 字面量 undefined
  • 对象字面量 {name: "John Doe", age: 30, city: "New York"}
  • 函数字面量 function myFunction() { return "Hello World"; }

JavaScript 变量

变量是存储数据的容器。 变量的名称通常用小写字母、数字和下划线组成。 变量的声明语法： var variableName = value;

JavaScript 有以下几种操作符：

  • 条件运算符 condition? expressionIfTrue : expressionIfFalse
  • 赋值运算符 简单的赋值运算符 = 加法赋值运算符 + 减法赋值运算符 - 乘法赋值运算符 * 除法赋值运算符 / 取模赋值运算符 %
  • 逗号运算符 var x = 1, y = 2, z = 3;
  • 字符串连接运算符 "Hello " + "World"
  • 位运算符 & 按位与运算符 | 按位或运算符 ^ 按位异或运算符 ~ 按位取反运算符 左移运算符 << 右移运算符 >> 无符号右移运算符 >>>

JavaScript 字符集

JavaScript 使用 Unicode 字符集。 Unicode 联盟（Unicode Consortium）开发了 Unicode 标准（Unicode Standard）。他们的目标是使用标准的 Unicode 转换格式（即 UTF，全称 Unicode Transformation Format）取代现有的字符集。 Unicode 标准是一个成功的创举，在 HTML、XML、Java、JavaScript、E-mail、ASP、PHP 中都得到实现。Unicode 标准也得到许多操作系统和所有现代浏览器的支持。 UTF-8 UTF8 中的字符可以是 1 到 4 字节长。UTF-8 可以代表 Unicode 标准中的任何字符。UTF-8 向后兼容 ASCII。UTF-8 是电子邮件和网页的首选编码。

var 和 let 的区别

// 使用 let 关键字 let text1 = He's often called "Runoob"; console.log(text1); // 输出: He's often called "Runoob"

if (true) { let text2 = He's often called "Runoob"; console.log(text2); // 输出: He's often called "Runoob" console.log(typeof text2); // 输出: string } // console.log(text2); // ReferenceError: text2 is not defined here

// 使用 var 关键字 var text3 = He's often called "Runoob"; console.log(text3); // 输出: He's often called "Runoob"

if (true) { var text4 = He's often called "Runoob"; console.log(text4); // 输出: He's often called "Runoob" console.log(typeof text4); // 输出: string } console.log(typeof text4); // 输出: string，即使在 if 块外也能访问

  1. 变量声明关键字： 第一行使用了 let 关键字，这是在 ES6（ECMAScript 2015）中引入的新的变量声明关键字，用于块级作用域的变量声明。 第二行使用了 var 关键字，这是 ES5 及之前版本中用于函数作用域或全局作用域的变量声明。

  2. 作用域： let 关键字声明的变量 text 具有块级作用域，这意味着它只在声明它的代码块（例如 if 语句、for 循环、函数等）内部可见。 var 关键字声明的变量 text 具有函数作用域或全局作用域，这意味着它在整个函数内部或全局范围内可见，而不是在块级范围内。

  • var的全局变量 var carName = " Volvo"; // 此处可调用 carName 变量 function myFunction() { // 函数内可调用 carName 变量 }
  • var的局部变量 // 函数外不可调用 carName 变量 function myFunction() { var carName = " Volvo"; // 此处可调用 carName 变量 }

注意： 在现代 JavaScript 开发中，推荐使用 let 和 const 来代替 var，因为它们提供了更好的作用域控制和更少的意外行为。

字符串模板/模板字符串

JavaScript 中的模板字符串是一种方便的字符串语法，允许你在字符串中嵌入表达式和变量。 模板字符串使用反引号 `` 作为字符串的定界符分隔的字面量。 模板字面量是用反引号（`）分隔的字面量，允许多行字符串、带嵌入表达式的字符串插值和一种叫带标签的模板的特殊结构。

  1. 语法 `string text` `string text line 1` `string text line 2` `string text ${expression} string text`

tagFunction `string text ${expression} string text` 参数

string text：将成为模板字面量的一部分的字符串文本。几乎允许所有字符，包括换行符和其他空白字符。但是，除非使用了标签函数，否则无效的转义序列将导致语法错误。

expression：要插入当前位置的表达式，其值被转换为字符串或传递给 tagFunction。

tagFunction：如果指定，将使用模板字符串数组和替换表达式调用它，返回值将成为模板字面量的值。
