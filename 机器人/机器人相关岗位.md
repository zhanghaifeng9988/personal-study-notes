# **机器人测试员**  8-13K
## 职位描述
1. 整机测试：协助工程师进行机器人整机产品测试，包括运动控制测试、VLA测试、交互测试以及涉及到室外的场景测试；
2. 机器人装配与维保：进行机器人装配、维修、保养工作，包括整机装配、整机维修、更换零部件等；

## 职位要求
1. 大专及以上学历，电子电气、自动化、机械、汽修等相关专业；
2. 从事过机器人、电子消费品、汽车零部件等行业，具备装配、维修相关工作经验；

# **应用工程师（机器人）** 10-15K·13薪
## 岗位职责：
1. 负责机器人本体、视觉系统、力控传感器等核心部件的现场安装、系统联调与性能优化。
2. 根据客户场景需求，进行机器人应用程序的编写、任务流程的在线示教与调试。
3. 在客户现场快速诊断并解决机器人运行中出现的机械、电气、软件或算法类问题，提供根本原因分析及预防方案。
4. 承担基础电气程序调试工作，保障系统稳定运行。
5.收集并提炼客户在真实使用中的需求、痛点与改进建议，形成结构化报告，反哺给研发与产品团队，驱动产品持续迭代.
6. 参与现场陪产，快速响应并处理技术问题，完成客户培训。

## 任职要求：
1.机器人技术，机械工程，自动化，电气工程等相关专业专科及以上学历。  
2.熟练掌握至少一种主流机器人（如KUKA, Franka Emika, Universal Robots等）或人形机器人平台的编程与应用。
3.熟悉视觉、激光跟踪、离线编程等先进技术优先。 
4.能够集成机器人周边设备，有机器人上下料、装配、焊接、喷涂等典型应用经验的优先。
5.沟通能力好，逻辑思维能力强，具备良好的动手和培训能力
6.具备良好的编程能力，能使用 Python 或 C++ 进行机器人控制脚本、算法原型验证或工具开发者优先

#  **复合机器人结构装配工程师**  9-11K·13薪
## 岗位职责
1.按照机械结构设计图纸和装配工艺要求，进行机器人机械部分的组装工作，确保装配质量和精度符合要求。
2.在装配过程中，对装配工艺进行优化和改进，提高装配效率和质量，及时发现并解决装配过程中出现的问题。
3.对装配完成的机械结构进行质量检验，确保产品质量符合标准要求，对检验过程中发现的质量问题进行记录和反馈，并协助相关部门进行整改。
4.负责对装配设备进行日常维护和保养，确保设备的正常运行，及时发现并处理设备故障，保障生产的顺利进行。
5.协助技术部门进行新产品的试制和调试工作，提供装配方面的技术支持和建议。
## 任职要求
1.中专或大专及以上学历，机械制造、机电一体化等相关专业。
2.具有 3 年以上机械装配工作经验，有机器人装配经验者优先，能够熟练看懂机械装配图纸。
3.具备较强的动手能力和实际操作经验，熟悉机械装配工具和设备的使用方法。
4.工作认真负责，具有较强的质量意识和安全意识，能够严格遵守装配工艺和操作规程。
5.具备良好的沟通能力和团队合作精神，能够与其他部门协作完成工作任务。
